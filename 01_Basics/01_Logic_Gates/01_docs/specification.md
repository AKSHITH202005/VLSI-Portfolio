# Logic Gates Library

## Project Overview

This project implements the seven fundamental digital logic gates using Verilog HDL.

The project demonstrates multiple RTL modeling techniques used in ASIC and FPGA design.

---

## Objectives

- Learn Verilog HDL
- Understand combinational logic
- Practice RTL coding
- Develop self-checking testbenches
- Generate simulation waveforms
- Build a professional VLSI portfolio

---

## Logic Gates

1. AND
2. OR
3. NOT
4. NAND
5. NOR
6. XOR
7. XNOR

---

## Modeling Styles

Each gate will be implemented using:

- Gate-Level Modeling
- Dataflow Modeling
- Behavioral Modeling (where applicable)

---

## Tools Used

- VS Code
- Icarus Verilog
- Verilator

- GitHub

## Verification

Each module will include:

- Testbench
