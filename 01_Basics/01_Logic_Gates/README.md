# Logic Gates Library

## Description

This project implements the basic digital logic gates using Verilog HDL.

## Gates

- AND
- OR
- NOT
- NAND
- NOR
- XOR
- XNOR

## Tools

- Icarus Verilog
- Verilator
- Git
- GitHub

## Project Structure

01_docs → Documentation

02_rtl → RTL Source

03_tb → Testbench

04_waveforms → Simulation Results

05_reports → Reports

06_diagrams → Diagrams
