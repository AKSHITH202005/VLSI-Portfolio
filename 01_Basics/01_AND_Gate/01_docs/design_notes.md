# Design Notes

## RTL

RTL stands for Register Transfer Level.

RTL describes how digital hardware transfers data between registers and the combinational logic operating on that data.

---

## Verilog

Verilog is a Hardware Description Language (HDL).

Unlike software languages, Verilog describes hardware that operates in parallel.

---

## Combinational Logic

Outputs depend only on current inputs.

Examples:

- Logic Gates
- Multiplexers
- Encoders
- Decoders

---

## Sequential Logic

Outputs depend on:

- Current inputs
- Previous state

Examples:

- Flip-Flops
- Registers
- Counters
- FSMs
